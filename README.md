# 会议全套物料策划

沿着一场会议的实际流程，整理需要哪些物料、在哪里使用、写什么、做多大、做多少，以及目前处于什么制作状态。

技能名称：`meeting-materials-plan` · [查看技能指令](SKILL.md)

## 适合什么时候用

- 筹备会议、论坛或发布活动，需要完整物料清单。
- 已经有清单，但陆续增加物料，编号和规格容易遗漏。
- 会务、设计和制作团队需要共用一份可编辑表格。

## 开始前准备什么

- 正式会议名称、主题、日期、地点和活动流程。
- 已有物料清单、参考文件及尺寸或制作规格。
- 数量、使用位置、确认状态和输出文件要求。

## 工作方式

1. 先确认会议基本信息，缺失项明确标为待确认。
2. 按邀请、接待、签到、导视、舞台、座席和交通等环节核对。
3. 建立含文案、宽高、单位、数量、状态和来源的物料表。
4. 新增项目时同步编号和统计，检查表格编辑及打印体验。

## 可以得到什么

- 可编辑的会议物料清单；需要时按要求输出 XLSX。
- 每件物料对应的使用位置、定稿文案和规格状态。
- 待确认数量、尺寸及工厂制作要求。

## 安装与调用

将完整仓库克隆到自己的技能目录，安装文件夹使用技能名称 `meeting-materials-plan`：

```sh
git clone https://github.com/AndrewDavidWY/Sill-meeting-materials-plan.git ~/.codex/skills/meeting-materials-plan
```

如果使用自定义 `CODEX_HOME`，请放到其 `skills/` 下。同名目录已经存在时先比较版本并保留自己的修改，不要直接覆盖。下载 ZIP 时，同样需保留完整文件结构，并把解压后的安装目录命名为技能名称。

在新会话中确认技能可用，再用下面的方式提出任务：

```text
使用 $meeting-materials-plan，根据会议流程和附件整理物料清单，输出可编辑表格。保留我的原始项目，缺少的尺寸和数量标为待确认。
```

## 使用边界

16:9 等屏幕比例不能直接当作印刷尺寸。讲话稿、致辞手卡与开幕致辞背景画面是不同交付物，按实际需求分别列明。
